# AI Resume Matcher

AI-powered web application that analyzes resumes against job descriptions using Natural Language Processing, semantic similarity, and skill matching.

## Features

- User authentication
- Resume PDF/DOCX upload
- Resume text extraction
- Skill extraction
- Job description analysis
- Semantic similarity
- AI-powered match scoring
- Missing skill identification
- Strength and weakness analysis
- Personalized recommendations
- Match history
